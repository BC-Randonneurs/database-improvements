# database-improvements
An empty repo for filing improvements on the BCR Database

## Filing issues

[Choose Bug report or Feature request](https://github.com/BC-Randonneurs/database-improvements/issues/new/choose) and complete every required field.

Bug reports require steps to reproduce, expected behavior, actual behavior, and impact. Feature requests require a target user, functionality, and considerations. Write None when there are no additional considerations.

Blank issue creation is disabled for regular contributors. Maintainers can still create blank issues, and API submissions can bypass the forms. Existing issues are unaffected.
